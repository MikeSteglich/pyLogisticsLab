# Beiträge zu pyLogisticsLab

Beiträge sind willkommen: Fehlermeldungen, Vorschläge und Pull Requests.

## Fehler und Vorschläge

Bitte als Issue auf GitHub melden. Bei Fehlern helfen die Version, das Betriebssystem, die Szenario-Datei und der Auszug aus den Logdateien (`logs/`).

## Pull Requests

- Vor größeren Änderungen bitte erst ein Issue anlegen, damit wir den Weg abstimmen können.
- Code und Kommentare folgen dem Stil der umgebenden Dateien.
- Die Tests in `tests/` müssen weiter laufen.
